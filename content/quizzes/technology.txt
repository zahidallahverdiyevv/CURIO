# programming-concepts
What is a variable in a program?|A named reference to a value|A mandatory external network connection|A physical processor manufacturing process|A complete copy of the operating system|Variables let programs refer to values that may change or be bound differently during execution.
What does a loop allow a program to do?|Repeat a set of operations|Choose one conditional branch|Store a value for later use|Define an input for a function|Loops express repeated execution subject to a count or condition.
What is a function's parameter?|An input named in its definition|The value printed by every program|The file extension of its source code|The amount of memory installed in a computer|Parameters describe inputs accepted by a function; arguments are values supplied when it is called.
What is a Boolean value?|True or false|A signed whole number|An ordered sequence of characters|A fractional numeric value|Boolean logic uses two truth values, often represented as true and false.
What is an algorithm?|A defined procedure for solving a problem|A particular manufacturer's processor model|The graphical appearance of an application|The physical cable used by a network|An algorithm specifies a sequence or structure of steps for carrying out a task.
What usually distinguishes a list from a set in abstract data structures?|A list has positions; a set has unique members|A list enforces uniqueness; a set defines positions|A list removes duplicates; a set retains repeated members|A list is unordered; a set assigns numeric indexes|Lists are ordered sequences, while mathematical sets do not retain duplicate members; language implementations may add ordering behavior.
What is a base case in recursion?|A condition that stops further recursive calls|The original call before the first recursive call|The rule combining results from recursive subproblems|The expression that creates the next recursive call|A terminating case prevents recursion from continuing indefinitely when the recursive process reaches it.
What does a unit test aim to check?|A small, focused behavior of a program|The interaction between integrated program modules|The complete application under a high request load|The product's acceptance by its intended users|Unit tests check limited behaviors in isolation or with controlled dependencies; they do not prove complete correctness.
Which design lets a calculation be tested without reading a file?|Pass parsed values into a calculation function|Open and parse the file inside that calculation|Store the file path in a shared global variable|Print the result instead of returning any value|Separating parsing from calculation allows controlled values to be supplied directly during a test.
For a sorted array, what does binary search repeatedly do?|Discard roughly half the remaining search interval|Compare the target with every element in order|Sort the whole array after each comparison|Build a new array containing every duplicate value|Binary search uses order to narrow the interval, giving logarithmic comparison growth under its standard assumptions.
Starting with x = 1, a loop repeatedly doubles x while x < 20. What is x immediately after the loop ends?|32|16|20|64|The successive values are 1, 2, 4, 8, 16 and 32; the loop stops when the condition x < 20 becomes false.
Why can caching a function's results be incorrect if the function depends on changing external state?|Identical arguments may produce different results later|The argument-based key automatically captures all external dependencies|Every cached value is checked against its source before reuse|A cache changes the function's external dependencies into local variables|Memoization needs keys or invalidation rules that account for relevant dependencies.
For each i from 1 through n, an inner loop runs i times. What is the exact number of inner-body executions?|n(n + 1)/2|n²|n(n − 1)/2|2n|The count is 1 + 2 + … + n = n(n + 1)/2; its asymptotic growth is quadratic even though the inner bound changes.
A copied object shares a nested list with the original. What kind of copying most likely occurred?|A shallow copy|A deep copy|An immutable copy|A serialized copy|A shallow copy duplicates the outer container while retaining references to nested objects.
Why can two threads each performing 'read, add one, write' lose an increment?|Their read-modify-write sequences can interleave|Thread creation implicitly serializes access to the shared value|Reading a shared value automatically acquires mutual exclusion|Writing the new value merges updates from competing threads|Without suitable synchronization or atomic operations, both threads can read the same old value and overwrite one another's updates.
# internet-networks
What is DNS commonly used to do?|Resolve domain names to network information|Encrypt the contents of every website|Compress video for a slower connection|Assign keyboard shortcuts inside a browser|DNS maps names to records, including addresses used to locate internet services.
What is an IP address used for in networking?|Identifying an interface for packet delivery|Specifying a webpage's font family|Measuring the age of a server's processor|Recording a browser's entire search history|IP addresses support addressing and routing at the network layer.
What is a router's basic role?|Forward packets between networks|Display the contents of HTML pages|Create a new password for every user|Convert source code into machine instructions|Routers use network information to direct packets toward their destinations.
What does HTTPS add to ordinary HTTP communication?|Transport protection using TLS|A guarantee of honest site ownership|Protection from every browser exploit|Automatic encryption of stored server files|HTTPS protects data in transit through TLS but does not by itself establish that a site's content or owner is trustworthy.
What does bandwidth describe in a common networking context?|The capacity of a communication link|The time taken for one packet to make a round trip|The number of pixels displayed by a monitor|The physical mass of a network cable|Bandwidth concerns capacity; latency concerns delay, and actual throughput can be lower than capacity.
Why can a high-bandwidth connection still feel slow for interactive tasks?|Round-trip latency can remain high|Throughput must fall as capacity rises|Bandwidth measures response delay directly|Link capacity eliminates server delay|Latency affects how quickly responses return even when large data transfers are possible.
Which service does TCP normally provide to an application?|An ordered, reliable byte stream|A reliable, boundary-preserving message service|A fixed-delay datagram delivery service|A permanently fixed packet routing path|TCP handles ordering and retransmission at its transport layer; applications still need to manage their own semantics and failures.
What distinguishes a private LAN address from a public internet address?|Its intended scope is within private networks|Its numeric value proves that the traffic is encrypted|Its assigned host is guaranteed to use a permanent address|Its scope is determined by the web browser's display settings|Private address ranges are reserved for internal use and are not globally routed as ordinary public addresses.
Why do content delivery networks place caches in multiple regions?|To serve content nearer to users|To remove cache expiry requirements|To replace the need for DNS lookups|To centralize every content computation|Nearby caches can reduce latency and distribute load, while cache policy and origin behavior still matter.
What does a port number help identify?|A transport-layer endpoint or service|The host's network-layer routing prefix|The interface's physical link-layer address|The DNS zone's authoritative name-server record|Transport protocols use ports to distinguish communication endpoints on a host.
Why does successful DNS resolution not prove a website is reachable?|Routing, server or transport failures can remain|A resolved name establishes an open application port|An address lookup supplies a trusted server certificate|DNS completes the application transaction on lookup|Finding an address is one stage; reaching the service and obtaining a response require further successful steps.
What can cause packets from one communication to arrive out of order?|Different routes or variable network delays|Transport ports assign every packet a new network|A DNS label sets packet priority along the route|A MAC address encodes application message order|Packet networks can introduce different delays; protocols such as TCP can reorder data before delivering it to applications.
Why might increasing bandwidth not speed up a request dominated by a slow database query?|Server processing remains the bottleneck|Link capacity determines query CPU time|Client bandwidth fixes the rows examined|More bandwidth reduces the query's data size|End-to-end performance is limited by the stage consuming the most relevant time or capacity.
Why does UDP's lack of built-in retransmission sometimes suit real-time applications?|Late data may be less useful than current data|UDP waits for missing datagrams before delivery|UDP supplies an ordered stream with retransmission|UDP compresses media before network transmission|Applications can choose how to handle loss and delay rather than inheriting TCP's ordered-stream behavior.
What distinguishes authentication of a server certificate from DNS resolution?|Verifying a claimed server identity versus locating records|Selecting the fastest route versus measuring the packet payload|Assigning an IP address versus translating a private network address|Rendering HTML versus selecting a transport-layer port number|DNS supplies records; certificate validation helps verify identity within the TLS trust model.
# cybersecurity-basics
What is phishing?|Deception aimed at obtaining information or actions|A test of how quickly a hard drive can read data|A method for reducing a video's file size|A process for assigning local printer addresses|Phishing uses deceptive messages or sites to induce disclosures or harmful actions.
Which is an example of a second authentication factor beyond a password?|A physical security key|A second memorized PIN|Another security-question answer|An extra password phrase|A security key supplies possession-based evidence, distinct from another knowledge-based secret.
What does encryption primarily protect when properly used?|Data confidentiality|Data integrity|Service availability|Message authenticity|Encryption limits intelligibility without the key; integrity and authenticity require suitable additional properties or modes.
What is a backup?|A recoverable copy of data|A pointer to an original file|A live synchronization setting|A file-deletion confirmation|A useful backup supports restoration and must be protected and tested appropriately.
Why should software updates be applied when they fix security flaws?|They can remove known vulnerabilities|They guarantee that the device will never be attacked|They replace the need for any account permissions|They turn public data into secret information automatically|Security updates address particular flaws, while other protective measures remain necessary.
Why is a unique password for each service useful?|One breach is less likely to expose other accounts|Uniqueness prevents deceptive sign-in pages|A unique secret replaces possession-based factors|Uniqueness makes a short password resist guessing|Reused credentials let one compromise spread through credential-stuffing attempts.
What is the principle of least privilege?|Granting only the access needed for a task|Granting broad access mainly on personal trust|Retaining former-role permissions for possible future use|Assigning identical record access to every signed-in user|Access should be limited to relevant duties and reviewed as those duties change.
Why is hashing a password different from encrypting it for later recovery?|A secure password hash is intended for verification, not reversal|A password hash is encryption with a publicly stored decryption key|Encryption and hashing both require recovering the original during login|A hash validates a password by storing each character in a separate field|Password hashing uses appropriate slow schemes and salts; guessing attacks still need consideration.
What is a password salt used to do?|Make stored hashes differ across otherwise identical passwords|Serving as a hidden decryption key for the original password|Replacing the slow work factor in a password-hashing scheme|Storing a reversible copy of the user's authentication secret|Unique salts reduce the usefulness of precomputed tables and cross-account hash matching.
Why can a fraudulent website use an HTTPS connection with a valid certificate?|Transport encryption does not establish business honesty|Certificate issuance verifies the seller's advertised products|TLS prevents the site operator reading submitted form data|Encrypted transport establishes the accuracy of page content|HTTPS protects the connection and authenticates the endpoint within its certificate model; it does not certify the operator's honesty.
Why is a single-use, expiring recovery link safer than a permanent reusable link?|Its usefulness is constrained after use or time passes|Expiry establishes that the person opening the link owns the account|One-time use encrypts the email channel carrying the recovery message|An expiring token prevents its URL from being copied before use|Expiry and one-time use limit exposure, but links must still be protected and recovery flows carefully designed.
What flaw allows a user to access another person's record by changing an identifier?|Broken object-level authorization|SQL command injection|Cross-site request forgery|Credential-stuffing attacks|The server must authorize access to each object, not merely check that a request has a familiar identifier.
Why can deleting an account fail to invalidate an already-issued signed access token immediately?|Token validation may not check current session state|Deletion changes the token's signed expiration immediately|Signature verification queries current deletion state|Deleting an account erases every copy of its issued token|Stateless token verification can remain valid until expiry unless the system checks revocation or session state.
What does parameterized SQL chiefly help prevent?|User input changing SQL command structure|An attacker reading an unencrypted network packet|An attacker guessing an unsalted password hash|User input running as JavaScript in a web page|Parameters separate supplied values from SQL syntax when used correctly; they do not replace transport protection, password hashing or output handling.
Why is an untested backup a weak recovery guarantee?|It may be incomplete, corrupt or inaccessible|Its presence proves application recoverability|A copy log establishes successful restoration|Current replication replaces historical recovery|Restoration testing checks whether the retained data and recovery process actually support recovery.

What does a model's training data provide?|Examples from which patterns can be learned|A guarantee of correct answers to future questions|A complete explanation of every internal decision|A replacement for the program used to run the model|Training data shapes learned patterns but does not guarantee generalization or explain every decision.
What is classification in machine learning?|Assigning inputs to categories|Predicting a continuous numerical value|Finding unlabeled groups of similar inputs|Learning an action policy from rewards|Classification predicts categories, whereas regression commonly predicts numerical quantities.
An AI labels an image as a cat with a confidence score of 0.9. What does this number directly report?|The model's assigned score|The number of training images|The image's storage quality|The cat's measured age|A confidence score is output by the model; treating it as a reliable real-world probability requires checking calibration.
What is a generative model designed to do?|Produce outputs resembling learned data patterns|Display only exact copies of its source-code instructions|Determine legal ownership of every training example|Guarantee factual truth for every generated sentence|Generative models produce content from learned structure, with reliability depending on the task and system.
What is overfitting?|Learning training-specific patterns that generalize poorly|Having insufficient capacity to fit even the training patterns|Evaluating on data kept separate from parameter fitting|Reducing the model's sensitivity to accidental training variation|A model can fit training data closely while failing on new data, including by learning noise or accidental correlations.
Why keep a test set separate from training?|To estimate performance on unseen examples|To tune parameters on the final evaluation answers|To duplicate convenient examples from the training set|To replace task-specific error analysis with one score|Held-out data supports evaluation of generalization when it is used carefully and not repeatedly optimized against.
What is data leakage in model evaluation?|Unavailable target information enters the training or evaluation setup|A dataset is transferred to an authorized long-term backup service|A training algorithm compresses input images before fitting the model|A model uses a publicly documented numerical optimization method|Leakage can create misleading performance by exposing information that would not be available in real use.
Why can high overall accuracy hide poor minority-group performance?|Errors can be concentrated in a small subgroup|The overall score weights every subgroup equally|Each subgroup inherits the combined accuracy value|The minority group sets the entire error rate|A large group can dominate the combined score, concealing weaker performance on a smaller group.
What is distribution shift?|New data differs meaningfully from training conditions|Changing the format of an output report without changing its data|Reusing one training example during several optimization passes|Moving a dataset between folders while its examples remain unchanged|Changes in input patterns or relationships can reduce reliability outside the training distribution.
Why might a model predict pneumonia partly from hospital-specific image markers?|It learned a shortcut correlated with the labels|It established a causal effect of the image marker|It ran a controlled clinical trial of the marker|It excluded hospital identity from the fitted signals|Spurious correlations can support impressive test scores without learning the intended medical signal.
Only 1% of cases are positive. A classifier predicts negative for every case. What is its positive-class recall?|0%|1%|50%|99%|It identifies none of the actual positive cases, so recall is zero despite 99% accuracy.
What does retrieval-augmented generation add to a language-model workflow?|Relevant retrieved material as additional context|A proof that retrieved sources are factually complete|A constraint preventing contradiction of every source|A replacement of the model with a static search index|Retrieval can provide evidence or context, but source quality, relevance and faithful use still require evaluation.
Why does correlation between an input and an outcome not establish fairness of using it?|It may proxy sensitive attributes or historical disadvantage|Correlation establishes appropriate use across contexts|Prediction accuracy removes the need to inspect labels|A numerical score makes historical disadvantage irrelevant|Predictive usefulness and appropriate, fair use are separate questions requiring context and scrutiny.
Why is an explanation that sounds plausible not sufficient evidence of a model's actual reasoning process?|Generated explanations may not faithfully trace the computation|The explanation's fluency establishes its calibration on unseen examples|A longer explanation reveals the complete computational state behind the answer|The generated account is a verbatim trace of every parameter interaction|Explanations should be assessed for faithfulness rather than accepted solely because they are coherent or persuasive.
# digital-electronics
How many distinct values does a binary digit represent?|Two|Three|Eight|Ten|A bit takes one of two logical values, usually written 0 and 1.

What does an analog-to-digital converter produce?|Digital samples of an analog signal|An analog output from a binary number|A higher mains voltage from a lower one|A mechanical rotation from an electric current|An ADC represents sampled analog values using a finite set of digital codes.
Which unit measures electrical resistance?|Ohm|Volt|Ampere|Farad|Resistance is measured in ohms; voltage, current and capacitance use the other listed units.
For which two-input state do XOR and OR give different outputs?|Both inputs are 1|Both inputs are 0|The first is 1 and the second is 0|The first is 0 and the second is 1|OR returns 1 for two high inputs, whereas XOR returns 0; their outputs agree for the other three combinations.
Why do digital inputs use voltage ranges rather than one exact voltage per bit?|Real signals include variation and noise|Logic requires infinitely precise voltages|Inputs are independent of voltage thresholds|High and low ranges must fully overlap|Threshold ranges and noise margins accommodate nonideal voltages while preserving logical interpretation.
What can a flip-flop store?|One bit of state|One byte of state|One processor word|One analog sample with unlimited precision|A flip-flop is a basic sequential storage element with two logical states.
What does a clock signal help coordinate in a synchronous digital circuit?|When state updates occur|The amplitude of analog sensor outputs|The resistance of the semiconductor|The power supply's voltage reference|Clock edges coordinate state changes under timing constraints; the clock is not a guarantee of error-free operation.
What is a pull-up resistor commonly used for?|Biasing an undriven input high|Rectifying an alternating supply|Retaining a bit without power|Amplifying an output voltage|A pull-up connects an input toward the supply through resistance while allowing another device to pull it low.
A four-bit two's-complement value is 1101. What signed integer does it represent?|-3|-5|5|13|The leading bit has weight −8, so 1101 represents −8 + 4 + 0 + 1 = −3.

What is metastability in a digital storage element?|A temporary unresolved state near a sampling boundary|A permanent reversal of the storage element's logical truth table|A deliberate clock division that halves the sampling frequency|A stable additional logic level used to store a third bit value|Sampling near a timing transition can leave a storage element temporarily outside a clean logical state.
Why can a mechanical pushbutton need debouncing?|Its contacts may produce several rapid transitions|Its output is a smoothly varying analog signal by design|Its contacts divide the clock frequency by a fixed ratio|Its internal memory stores one bit for each physical press|Contact bounce can turn one press into several apparent edges; hardware or software can filter the transitions.
Which two-input function equals NAND(NAND(A,A), NAND(B,B))?|OR|NOR|AND|XOR|The inner NAND gates invert A and B. The outer NAND negates their conjunction, which is A OR B by De Morgan's law.
